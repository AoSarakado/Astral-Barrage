# Kerr–Newman shader source

- Original work: [Kerr Newman Black Hole](https://www.shadertoy.com/view/wXdfzj) by baopinsui.
- Source snapshot: the public `wXdfzj.json` archived in
  [WallDisplay](https://github.com/abhidya/WallDisplay/blob/47961d107bc25f2efb7a3398da98d09ea0647cf2/web/backend/static/assets/shadertoy/wXdfzj.json).
  Its ShaderToy metadata timestamp is 2026-02-10 18:33:54 UTC; SHA-256:
  `487C74AD06261AE7391D5B365FD1DCD443F4C5825C4502BEF0CE59B29B68D723`.
- The five GLSL files preserve the snapshot's Image and Buffer A–D shader logic;
  whitespace was normalized. Each
  file adds a GLSL 330 header, ShaderToy uniforms, and a `mainImage` entry
  wrapper for raylib. The source comments credit sonicether's
  [Gargantua With HDR Bloom](https://www.shadertoy.com/view/lstSRS) for parts
  of the bloom pipeline.
- baopinsui's related [NPGS repository](https://github.com/baopinshui/NPGS)
  is published under GPL-3.0. The exact license for this archived ShaderToy
  snapshot, including the credited bloom portions, has not been independently
  established. Confirm redistribution rights with the authors before
  publishing a game that contains these files.
